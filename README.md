# App-Know-How

База практических знаний о разработке приложений: выполненные эксперименты, ограничения и способы реализации.

В материалах отдельно фиксируются:

- **Что работает** — наблюдаемые результаты с условиями проверки.
- **Что не работает** — отрицательные результаты, нерешённые задачи и границы выводов.
- **Ноу-хау** — практические приёмы и детали реализации.

Успешная сборка не заменяет проверку поведения на устройстве. Предположения и непроведённые проверки отмечаются отдельно.
